# 语录库与生成公式

## 一、句式公式

```
承认坏  →  但有个东西不变
```

**前半句是「承认」**：把用户的处境平铺出来，不评价、不打气、不给建议。
**后半句是「锚点」**：陈述一个**事实层面的不变**。

### 为什么是这个公式

它**不做安慰**。安慰是假的——"一切都会好的"用户自己都不信。

但它说的是一个事实：薯条的口感，真的不会因为今天被否了就变。**这是唯一一种不显得轻浮的陪伴。**

### 写作禁忌

- 不用"没关系""没事的"开头——那是替用户下结论
- 不用范围词（"很多人""大家"）——用户此刻只有自己
- 不用鼓励动词（加油、撑住、会好的）
- 锚点必须是**具体的**，不能是抽象的信念

对错对照：

| 差 | 好 |
|---|---|
| 一切都会好起来的 | 白干也是干过了。巨无霸不会问你为什么。 |
| 加油，明天会更好 | 今天这班，上得像被生活按在桌上摩擦。但薯条还是脆的，一根都没塌。 |
| 别难过，吃点甜的开心一下 | 难受就难受吧，不用急着好起来。冰可乐已经在杯子里等你了。 |

## 二、参数化插槽

固定句保证质量，插槽保证不重复。库容量 = 固定句 × 插槽组合数。

| 插槽 | 可选值 |
|---|---|
| `{时段}` | 今天 / 这周 / 这个月 / 这一年 |
| `{产品}` | 薯条 / 可乐 / 巨无霸 / 新地 / 麦乐鸡 / 咖啡 |
| `{状态}` | 被按在桌上摩擦 / 被反复退回来 / 卡在原地 / 一直没被看见 |

使用时**每次随机取一组**，同一用户连续两次对话不重复同一组合。

## 三、分类与示例库

按情绪类型分为六类。每类目标 15–25 条，当前为种子批次。

### A. 被掏空 / 累到不想说话

1. 今天这班，上得像被生活按在桌上摩擦。但薯条还是脆的，一根都没塌。
2. 你已经把力气都用完了，剩下的部分不用再硬撑。大薯就是为这种时候炸的。
3. 累到不想讲话也没关系。巨无霸不需要你回应它。
4. {时段}你的电量一直没充满过。先吃一口热的，再想别的。
5. 撑到今天已经很不容易了。别急着复盘，先让可乐在嘴里炸一下。
6. 你不是不够努力，是这一天太长了。

### B. 委屈 / 心里堵得慌

7. 白干也是干过了。巨无霸不会问你为什么。
8. 有些事本来就不该由你扛。先把它放桌上，凉了再说。
9. 你解释了很多次，对方也没打算听懂。那就不解释了。
10. 被误解是真的很难受。新地不会跟你争这个。
11. {状态}不是你的错，只是刚好轮到你。
12. 说不出来的话，可以先不说。吃口甜的，等一下再想。

### C. 焦虑 / 睡不着

13. 你现在想的所有事，明天也不会变得更清楚。但今晚可以先睡。
14. 焦虑不会因为你想得更多而变小。它只会因为天亮了而变小。
15. 深呼吸三次，不是为了放松，是为了确认你还在这儿。
16. 如果今天做不完，那就明天。麦当劳明天还开着。

### D. 还得继续撑 / 事情没做完

17. 还没到终点，但也别用跑的。先喝一口，再继续。
18. 你不是在拖延，你只是需要一点燃料。
19. 剩下的部分，可以一次做一点。咖啡在这儿，不着急。
20. 撑住不是唯一的选择，但如果你决定撑，这一份给你。

### E. 烦躁 / 坐不住

21. 有些烦是讲不出理由的。那就不用讲，咬碎点什么就行。
22. 你现在需要的不是建议，是一点脆的东西。
23. 坐不住就别坐了。出去走两步，顺便带一份回来。

### F. 开心 / 值得庆祝

24. 今天值得加个甜的。不用找理由。
25. 好日子就是要被记住。多来一份，算你请自己。
26. 这种时候不需要我说话。吃吧。

## 四、正向默认句（无情绪信息时使用）

用户只说"来一份"时，不要硬套语录。使用中性承接句：

- 好，看一下今天的。
- 行，给你挑一份。
- 收到。

## 六、扩充指引

新增语录时逐条自检：

1. 是否符合「承认 + 锚点」公式？
2. 锚点是否具体（有可感知的物）？
3. 是否出现了禁用词（加油 / 会好的 / 想开点 / 我理解你 / 建议你 / 一切都会好 / 没关系 / 没事的）？
4. 是否在替用户下结论？
5. 长度是否可控在 30 字内？
