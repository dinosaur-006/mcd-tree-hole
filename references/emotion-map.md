# 情绪映射与降级链

## 一、三段式结构

```
情绪  →  它真正需要的感官体验  →  承接它的产品
```

**中间的「感官需求」层不可省略。**

直接做"情绪 → 产品"是玄学配对，无法解释、无法维护、也经不起追问。加上中间层之后：

- 推荐变得**可解释**："你需要的不是甜，是需要被人好好对待一下的感觉"
- 硬约束可以**在中间层接管**：需求层稳定，产品层可替换。用户不吃冰时，不需要重做映射，只需在"要被安抚"这个需求下换一个承接产品

---

## 二、主映射表

| 情绪特征 | 它真正需要的 | 承接它的产品 | 降级链（依硬约束逐级下移） |
|---|---|---|---|
| 被掏空、累到不想说话 | 要被实实在在地填满 | 巨无霸 + 大薯 | → 双层吉士汉堡 + 中薯（预算不足）→ 吉士汉堡 + 小薯（忌牛则换）麦香鸡 + 大薯 |
| 心里堵得慌、说不出来 | 要被温柔地安抚 | 新地 | → 香芋派 / 菠萝派（不吃冰）→ 热红茶（忌乳制品）→ **认输** |
| 还得继续撑下去 | 要被提神拖住 | 咖啡 | → 热红茶（忌咖啡因）→ 无糖可乐（忌咖啡因且需凉感）→ 冰牛奶 |
| 闷、想哭但哭不出来 | 要来一下刺激冲开 | 雪冰 | → 阳光柠檬红茶（不吃冰则改热红茶）→ 冰可乐 → **认输** |
| 烦躁、坐不住 | 要有东西可以咬碎 | 麦乐鸡 | → 麦辣鸡翅（可吃辣）→ 那么大鸡排 → 脆香油条 |
| 开心、值得庆祝 | 要有一个仪式感 | 加一份甜品 | → 新地 / 圆筒冰淇淋 → 派 → 麦旋风 |

> 降级链中的每一级都必须**再回到第一层硬约束复核**（见 `SKILL.md` 第 3 步）。

---

## 三、"认输"出口

**降级链走到底仍然无解时，如实告知，不要硬凑。**

示例：

```
你   ：今天心里堵得慌，但我乳糖不耐又不吃冰的
树洞 ：那这一份我今天真给不了你。热红茶行吗？至少是口热的。
```

**硬凑一个不合适的东西，比承认给不了更伤信任。**

触发"认输"的常见情况：

- 忌口组合在麦当劳菜单内确实无对应产品
- 预算上限低于任何可行单品的价格
- 当前时段该门店没有可承接的商品（如深夜无甜品线）

---

## 四、时段对映射的影响

映射结果必须经过时段过滤。实测不同门店供餐时段差异极大（部分门店 22:00 打烊，部分宵夜营业至 23:59）。

- `now-time-info` 取当前时间 → 映射到 早餐 / 午餐 / 下午茶 / 夜市 / 宵夜
- 门店已打烊或目标商品不在当前时段供应 → **该条映射整条作废**，不是降级

**典型坑**：深夜 23:00 推荐"咖啡"会让用户更睡不着。咖啡因类产品在 21:00 之后应自动移出候选集，除非用户明确要。

---

## 五、复核清单

每次输出前逐条核对：

1. 映射给出的产品，是否已过第一层硬约束（过敏 / 忌口 / 宗教 / 不吃冰 / 控糖控钠）？
2. 是否在当前时段该门店在售？
3. 是否在用户预算内？
4. 降级链是否被正确触发，还是跳级了？
5. 无解时，是否走了"认输"出口而不是硬凑？
6. 情绪识别是否模糊？**模糊时不要猜**——回到用户原话 + 一句中性回应，不进入映射流程。
