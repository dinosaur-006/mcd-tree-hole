# 演示脚本

> 目标：在 3 分钟内让评审记住**一件事**——它不只是会推荐菜，它会先接住你，再给你东西；而且**它可以什么都不给**。

---

## 一、核心判断

情绪类产品在短时演示里最大的风险是：**评审看不到"打动"发生在哪一刻，只看到"又一个点餐助手"。**

所以演示不能从架构讲起，也不能从功能列表讲起。必须**先立一个反常识**，再用三个场景依次证明三件事：

| 场景 | 证明什么 | 时长 |
|---|---|---|
| 直接点餐 | 它**好用**（不是花架子） | 50 秒 |
| 情绪 + 降级链 | 它**有辨识度**（别人做不到） | 60 秒 |
| 不点单 | 它**可以被信任**（记忆点） | 30 秒 |

---

## 二、时间轴

### 0:00 – 0:20　开场：先立反常识

**不要从功能讲起。** 第一句就要说出那个处境：

> "现在所有的点餐 App 都在做同一件事——把二十个套餐推给你，让你自己选。
> 我要做的正好相反。"

停顿一秒，给定位：

> "不管你今天过得怎么样，麦当劳那一份是不变的。"

### 0:20 – 1:10　场景一：直接点餐（证明它好用）

**输入**：`来一份，两个人吃，预算 60`

**输出**：
```
看一眼今天的。
巨无霸 + 麦香鸡 + 中薯条买一送一
原价 69.50 元 · 实付 56.00 元 · 省 13.50 元
```

**关键台词**（说完停一下）：

> "注意，我全程没有选任何东西，它也没有让我选。"

> ⚠️ **不要在这个场景停留超过 50 秒。** 它只是地基，不是亮点。

### 1:10 – 2:10　场景二：情绪 + 降级链（证明辨识度）

**输入**：`今天上班又白干了`

**输出**：
```
白干也是干过了。巨无霸不会问你为什么。
巨无霸 + 新地 · 实付 37.50 元
```

然后**当场改口**（这一步是整个演示的技术高光）：

**输入**：`我不吃冰的`

**输出**：
```
换成黑洋酥小圆子风味派，热的。
巨无霸 + 黑洋酥小圆子风味派 · 实付 30.50 元 · 省 5.00 元
```

**关键台词**：

> "注意，这不是重新推荐。是同一条降级链往下走了一格——
> **它早就知道'要被安抚'这个需求有多少种接法。**"

### 2:10 – 2:40　场景三：不点单（制造记忆点）

**输入**：`算了，我就是想说说`

**输出**：
```
行，记下了。今天不用吃什么。
```

**关键台词**（这场演示最重要的一句）：

> "一个总在最后推你下单的地方，用户三天就会看穿。
> **不点单，在这里是一个正常的结局。**"

### 2:40 – 3:00　收尾

两句话，都不要展开：

1. **机制**：候选池 → 硬约束剔除 → 软偏好排序 → 安全兜底。硬约束只剔除，不参与打分——"不吃牛肉"不能和"口味偏咸"放在同一个函数里权衡。
2. **隐私**：账本和情绪日记全部存在用户本机。"**不是我们保证不看，是我们看不到。**"

## 三、口播稿全文（可直接照读）

> 现在所有的点餐 App 都在做同一件事——把二十个套餐推给你，让你自己选。我要做的正好相反。
>
> 不管你今天过得怎么样，麦当劳那一份是不变的。
>
> 我先试最普通的情况：来一份，两个人吃，预算六十。
>
> 它给了我一份搭配，五十六块，用掉了一张券，省了十三块五。注意，我全程没有选任何东西，它也没有让我选。
>
> 然后我换一个状态。今天上班又白干了。
>
> 它没问我怎么了，也没让我"想开点"。它说：白干也是干过了，巨无霸不会问你为什么。然后给了我巨无霸和新地。
>
> 我说我不吃冰的。它没有重新算一遍，而是把新地换成了热的黑洋酥小圆子风味派 —— 价格从三十七块五掉到三十块五。
>
> 这不是重新推荐，这是同一条降级链往下走了一格。它早就知道"要被安抚"这个需求有多少种接法。
>
> 最后，我说算了，我就是想说说。
>
> 它说：行，记下了，今天不用吃什么。
>
> ——一个总在最后推你下单的地方，用户三天就会看穿。不点单在这里是一个正常的结局。
>
> 推荐全程经过三层过滤：硬约束只做剔除，不参与打分。不吃牛肉，不能和口味偏咸放在同一个函数里权衡。
>
> 还有一件事：你的账本和你说过的话，全部存在你自己的电脑上。不是我们保证不看，是我们看不到。

## 四、演示前检查清单

- [ ] MCP 已连通，Token 有效（先跑一次 `now-time-info` 确认）
- [ ] 选一个**当前时段有营业**的门店，避免演示时踩到"已打烊"
- [ ] 用户档案提前清空或设好，避免演示出意外结果
- [ ] 优惠券状态确认（未授权时要说明"这里需要手机号授权"）
- [ ] 三个场景各预跑一次，确认输出的数字稳定
- [ ] 准备好"如果网络断了"的兜底：截图或本地演示页

## 五、禁忌

| 不要 | 原因 |
|---|---|
| 开场讲架构 | 评审还没被打动，听不进分层图 |
| 展示后台 JSON / 日志 | 会让"产品"变成"脚本" |
| 在场景一停留超过 50 秒 | 那是地基，不是亮点 |
| 用"情绪价值""赋能""闭环"这类词 | 会让作品听起来像 PPT |
| 用"我理解你""会好的" | 违反三不原则，也是产品红线 |
| 把不点单场景放在最后当"隐藏彩蛋" | 它是记忆点，必须讲，但不能显得像在狡辩 |

---

## 六、如果只有 60 秒

砍掉场景一，直接：**情绪 → 降级链 → 不点单**。

三句话讲完：
1. "它先说一句话，再给你一份算好价的搭配。"
2. "你说不吃冰的，它不是重算，是降级链往下走一格。"
3. "但你说只想说说的时候，它什么都不给。"
